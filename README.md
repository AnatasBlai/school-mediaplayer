# Табло расписания (Vue 3 + Vite)

## Запуск

| Файл | Что делает |
|---|---|
| `start.bat` | Запускает готовый сайт на порту **8080**. Если Node.js не установлен, ставит его через winget. |
| `dev.bat` | Режим разработки на порту **5173**: правите файлы в `src/`, и страница сразу обновляется. |
| `build.bat` | Пересобирает `dist/` после правок кода. Затем перезапустите `start.bat`. |

После запуска в окне будут адреса:
- `http://localhost:8080` — на этом компьютере;
- `http://<IP-компьютера>:8080` — с других устройств в сети, например с ноутбука, чтобы редактировать расписание.

При первом запуске Windows спросит разрешение для Node.js в брандмауэре. Разрешите доступ в частных сетях, иначе другие устройства не откроют сайт.

## Управление

- **Вкладки 5–11** переключаются сами, интервал задаётся в настройках ⚙ (правый нижний угол).
- **Клик по уроку или кабинету** выделяет его.
  - Повторный клик, `Enter` или просто начало ввода включает редактирование.
  - `Enter` или кнопка ✓ сохраняет, `Esc` отменяет.
  - `Delete` или `Backspace` на выделенной ячейке очищает её, место остаётся пустым.
  - Стрелки и `Tab` переходят между ячейками.
- Пока ячейка выделена, автолистание стоит на паузе.
- **Клик по дню в календаре** показывает расписание этого дня недели. Через 5 минут без действий табло само вернётся к сегодняшнему дню.
- Стрелки ← → (когда ничего не выделено) переключают параллели.

## Вкладка «Изменения»

Идёт после 11-х классов. В каждой строке три поля: класс, текст изменения и кабинет, они редактируются так же, как уроки.
В настройках ⚙ можно:
- задать отдельное время показа;
- убрать вкладку из автолистания;
- пропускать её, когда изменений нет;
- выбрать 2 или 3 колонки;
- очистить все изменения разом.

## Звонки

Блок под датой показывает идущий урок и сколько минут осталось до звонка. На перемене он показывает время до следующего урока.
Текущий урок подсвечивается в колонках, а следующий урок начинает мигать рамкой за 15 минут до начала.
Звонки редактируются в настройках ⚙: две группы дней, по строке на урок в формате `номер ЧЧ:ММ-ЧЧ:ММ`.
Звонки после последнего урока дня не учитываются. Поэтому 10-й урок в группе «Вт, Ср, Пт» срабатывает только там, где он есть в расписании.

## Цвета параллелей

Темы задаются в `src/themes.js`: 5 — янтарь, 6 — голубой, 7 — зелёный с жёлтым, 8 — красный с чёрным, 9 — киберпанк, 10 — нежно-розовый, 11 — фиолетовая магия, «Изменения» — коричневый с зелёным.

## Где хранятся данные

`data/schedule.json` создаётся автоматически. Все устройства видят одни и те же данные, табло подтягивает правки раз в 20 секунд.
Резервную копию можно скачать или загрузить в настройках.

## Свой фон

Положите картинку в `public/background.jpg` и выполните `build.bat`. Без неё используется тёплый градиент.

## Структура

```
src/App.vue                     шапка, вкладки, автолистание, клавиатура
src/components/EditColumn.vue    колонка с редактируемыми строками (уроки и изменения)
src/components/BellWidget.vue   блок «до звонка»
src/bells.js / src/themes.js     звонки и цветовые темы
src/components/CalendarPanel.vue  день недели, часы и календарь
src/components/SettingsModal.vue  настройки
src/store.js                    данные и сохранение на сервер
src/defaultData.js              стартовое расписание
api.js / server.js              API и сервер для start.bat
```

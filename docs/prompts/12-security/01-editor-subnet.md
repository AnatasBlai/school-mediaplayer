# Этап 12, задача 01. Редактор — только с компьютеров учителей

Сеть школы общая: ученики в кабинете информатики тоже могут открыть `/admin` и подбирать пароль. Нужно разрешить
редактор только с указанных компьютеров или подсетей. Экраны (`/`) не затрагиваются. Нужна задача 05 этапа 9 (права
«Администратор»), без неё — остановись и скажи владельцу.

## Как должно работать

- В окне «Пользователи» (или рядом, кнопка «Доступ к редактору», только администратор): переключатель «Открывать
  редактор только с этих компьютеров» и список адресов: отдельный адрес `192.168.1.25` или подсеть `192.168.1.0/24`,
  у каждой строки — подпись («Учительская»). Кнопка «Добавить этот компьютер» (подставляет адрес, который видит
  сервер, — показать его: «Этот компьютер: 192.168.1.40»).
- **Защита от того, чтобы запереть себя**: нельзя включить ограничение, если адрес текущего компьютера в список не
  входит, — сообщение «Сначала добавьте этот компьютер, иначе вы потеряете доступ». Сам сервер (`127.0.0.1`, `::1`)
  разрешён всегда.
- С неразрешённого компьютера:
  - страница `/admin` → простая страница «Редактор табло открывается только с компьютеров учителей. Обратитесь к …»
    (без загрузки кода редактора);
  - все записи в API и `/api/auth*` → 403 `{ error: 'Доступ к редактору с этого компьютера закрыт' }`;
  - экраны продолжают работать: `GET` данных, SSE, `POST /api/screens`, `POST /api/decks/<id>/take` открыты всем.
- Забыли и заперлись — открыть редактор на самом сервере (`http://localhost:8080/admin`) или удалить
  `data/access.json` (README).

## Данные и сервер

- `data/access.json` `{ on: false, allow: [{ net: '192.168.1.0/24', note }] }` ≤50 — новый `server/access.js`,
  разбор IPv4 и CIDR своей функцией (без зависимостей), `::ffff:` — снимать. IPv6 — только `::1`.
- Проверка в api.js **до** `isAllowed` и в server.js для пути `/admin`. В dev (Vite) — тоже через api.js.
- access.json — как users.json: не в снимках копий и не в архивах pack.mjs. Изменения — в журнал (если задача 06
  этапа 9 сделана).
- Тест в `tests/`: `ipInList('192.168.1.40', ['192.168.1.0/24'])`, /32, /16, мусор в списке.

## Проверка (копия сервера)

Копия слушает на всех интерфейсах; с адреса ПК разработки в сети (не localhost) — открыть /admin; включить
ограничение без своего адреса — нельзя; список только с `10.0.0.0/8` — с ПК разработки по сетевому адресу /admin
закрыт, `/` работает, через localhost — открыт. Удалить access.json — всё открыто.

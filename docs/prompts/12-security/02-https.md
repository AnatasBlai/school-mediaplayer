# Этап 12, задача 02. Защищённое соединение (HTTPS) для редактора — по желанию

Сейчас пароль и вход передаются по сети открытым текстом (HTTP). Нужна возможность открывать редактор по HTTPS.
Экраны остаются на HTTP 8080 — ничего на телевизорах не перенастраиваем.

**Перед началом спроси владельца**: браузеры будут предупреждать о «самоподписанном сертификате», пока сертификат
не установлен на компьютеры учителей. Готов ли он устанавливать сертификат (инструкцию напишешь) или достаточно
«принять риск» один раз в каждом браузере? От ответа зависит только README.

## Как должно работать

- `cert.bat` → `tools/cert.ps1` (UTF-8 с BOM): создаёт самоподписанный сертификат на имя компьютера и его адреса
  в сети (`New-SelfSignedCertificate`, срок 10 лет), экспортирует `cert/tablo.pfx` (пароль — случайный, рядом
  `cert/pass.txt`) и `cert/tablo.cer` (для установки на компьютеры учителей). Флаг `-DryRun` — показать, что будет
  сделано, ничего не создавая. Запуск без прав администратора должен работать (хранилище CurrentUser).
- server.js: если есть `cert/tablo.pfx` — дополнительно слушает **8443** по HTTPS (встроенный `node:https`, тот же
  обработчик). Нет файла — как сейчас, только 8080.
- Cookie входа при HTTPS — с флагом `Secure`. Настройка «Редактор только по HTTPS» (в окне «Доступ к редактору»,
  задача 01): запрос `http://…:8080/admin` → переадресация на `https://<тот же адрес>:8443/admin`; записи в API по
  HTTP → 403 «Откройте редактор по защищённому адресу». Экран по HTTP работает как раньше.
- Окно «Состояние системы»: строка «Защищённое соединение: включено, сертификат до 2036 г.» / «не настроено».
- `cert/` — не в git (.gitignore), не в архиве обновления; в архив установки не класть (сертификат создаётся на месте).
- `autostart` и `kiosk` не меняются.

## Проверка

`tools\cert.ps1 -DryRun` и разбор скрипта `[System.Management.Automation.Language.Parser]::ParseFile`; на копии сервера —
сертификат во временную папку (параметр `-OutDir`), Playwright с `ignoreHTTPSErrors`: /admin по 8443, вход, cookie
Secure; HTTP-переадресация при включённой настройке; экран по HTTP работает. **Не устанавливать** сертификат в
хранилища ПК разработки.

Работай по CLAUDE.md, версия — следующая `v0.12.x`. В CLAUDE.md: «Стек и запуск» (cert.bat, порт 8443),
«Подводные камни» — ps1 и сертификаты. README: «Защищённое соединение» с инструкцией для учителей.

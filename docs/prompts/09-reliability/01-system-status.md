# Этап 9, задача 01. Окно «Состояние системы»

Владельцу нужно одним взглядом понять, всё ли в порядке с табло: жив ли сервер, есть ли место на диске, делаются ли
копии, на связи ли экраны, верные ли часы.

## Как должно работать

- В шапке редактора (AdminApp) кнопка «Состояние». Рядом с ней точка: зелёная — всё хорошо, жёлтая — есть
  предупреждения, красная — есть ошибки. Окно `a-modal` — список строк «что проверено → состояние → подсказка».
- Строки:
  - **Версия табло** (из package.json) и **работает без перезапуска**: «3 дня 4 ч».
  - **Место на диске**, где лежит папка табло: свободно N ГБ. < 2 ГБ — жёлтое, < 500 МБ — красное
    («Освободите место: удалите неиспользуемые видео в Медиатеке»).
  - **Объём** data/ и media/ (число файлов, размер).
  - **Резервная копия**: последняя удачная — дата; выключена — жёлтое «Копии не делаются»; последняя попытка с
    ошибкой — красное с текстом ошибки; последняя удачная старше двух периодов — жёлтое. Кнопка «Открыть настройки
    копий» → BackupPanel.
  - **Экраны**: на связи N из M (по данным `/api/screens`, то же правило «на связи», что в NowOnScreen —
    `isOnline` из admin/screens.js).
  - **Часы**: разница между часами сервера и этого компьютера. Больше 2 мин — жёлтое «Часы расходятся на 5 мин —
    звонки на экранах могут показываться неверно» (звонки считаются по часам ПК с экраном).
  - **Пароль на редактор**: задан / не задан (не задан — жёлтое).
- Данные обновляются при открытии окна и кнопкой «Обновить». Точку в шапке пересчитывать при загрузке редактора и
  раз в 5 минут.

## Данные и сервер

- `GET /api/status` (новый файл `server/status.js`, подключить в api.js) → `{ version, startedAt, now, node,
  disk: { free, total }, data: { files, bytes }, media: { files, bytes }, backup: { period, lastAt, last },
  auth: { required } }`. Чтение открыто, как и прочие GET (в ответе нет секретов — проверь).
- Свободное место: `fs.statfsSync` (Node ≥ 18.15); если недоступно — как в server/backup.js (там уже есть сведения
  о дисках — переиспользуй, а не пиши второй способ).
- Состояние копий брать из backup.js через экспортируемую функцию, не читая backup.json напрямую.
- Под Vite (dev) `/api/status` тоже работает (общий api.js); `startedAt` — время загрузки модуля.

## Проверка (копия сервера)

Окно на 1920 и 1280 px; выключенные копии — жёлтая точка; подменить ответ (`page.route`) на диск 300 МБ и ошибку
копии — красная точка и подсказки; часы: подменить `now` на +6 мин — предупреждение.

в «Архитектуре». README: раздел «Состояние системы».

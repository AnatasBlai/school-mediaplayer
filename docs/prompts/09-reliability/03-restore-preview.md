# Этап 9, задача 03. Восстановление из копии с предпросмотром и выбором, что вернуть

Сейчас в «Резервной копии» можно только вернуть снимок целиком, не видя, что изменится. Если испортили одно
расписание, вместе с ним откатятся и новости. Нужно показать разницу и дать выбрать.

## Как должно работать

- В BackupPanel у каждого снимка кнопка «Посмотреть» → окно «Что изменится, если вернуть снимок от 14.10 18:00».
- В окне — разделы с галочками (по умолчанию отмечены те, где есть разница):
  - **Расписание** — список отличий по-человечески: «8А, вторник: 3 урока», «Звонки: изменены», «Буквы классов:
    добавлен 5Д», «Изменения: 4 строки». Не больше 30 строк, дальше «и ещё N».
  - **Плейлист** — «Будут возвращены слайды: …», «Пропадут слайды, добавленные позже: …», «Изменены: …» (по id,
    название — `slideTitle`).
  - **Колоды** — по колодам: добавленные/удалённые, «изменено карточек: N».
  - **Медиатека** (media.json) — «в снимке нет 3 файлов, добавленных позже» (сами файлы не удаляются — так и
    написать), «в снимке есть файлы, которых нет в медиатеке: …» (вернуть их можно, только если они есть в зеркале
    media/ в папке копий — проверь и скажи).
  - Нет разницы — «Совпадает с текущими данными», галочка выключена и неактивна.
- Кнопка «Вернуть отмеченное» → подтверждение → восстановление только отмеченных файлов. Перед этим текущие данные
  сохраняются снимком «перед возвратом» (это уже делает сервер — сохранить поведение).

## Данные и сервер

- `GET /api/backup/snapshot/<имя>/<файл>` → содержимое json из снимка. Имя снимка и файла — строго проверять
  (имя из списка снимков, файл — только из `isDataFile`, без `..` и слешей), иначе 400. Чтение открыто? **Нет** —
  в снимке могут быть личные данные; сделать этот GET только после входа (впиши проверку в server/auth.js
  `isAllowed`: GET `/api/backup/snapshot/*` требует входа).
- `POST /api/backup/restore { name, files?: ['schedule.json', …] }` — без `files` как сейчас (всё).
- Сравнение — чистый модуль `src/dataDiff.js` (без Vue): `diffSchedule(a, b)`, `diffPlaylist(a, b)`,
  `diffDecks(a, b)`, `diffMedia(a, b)` → массивы строк для показа. Тесты в `tests/`. Этот модуль понадобится
  журналу правок (задача 06), поэтому — без зависимостей от редактора.

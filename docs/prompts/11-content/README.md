## Новый тип слайда — где отметиться (общее для всех задач этапа)

Пропустишь место — слайд не сохранится или экран его не покажет:
1. `src/catalog.js` — `SLIDE_TYPES` (сервер берёт отсюда; если задача 17 не сделана — `TYPES` в server/playlist.js
   и server/decks.js);
2. `src/playlist.js` — `SLIDE_TITLES`, `makeSlide`, `slideTitle`, `hasLayout` (если у слайда бывает панель справа);
3. `server/playlist.js` — ветка в `cleanItem` (каждое поле с ограничением длины), иначе сервер выбросит слайд;
4. `src/display/Player.vue` — компонент слайда и условие в `playable()` (когда показывать нечего — пропускать);
5. редактор: пункт в AddSlideMenu.vue, окно правки (по образцу NewsEditor / CountdownEditor с живым превью),
   сводка в строке очереди;
6. CLAUDE.md, раздел «Данные» (формат слайда), «Архитектура» (новые файлы); README — раздел для пользователя.

Оформление — как у новостей: SlideStage с темой, стеклянные панели, Montserrat, тема из ThemeSwatches, `v-fit` для
длинного текста. Проверять обязательно 1280×720 и шаблон «с панелью справа».

# Этап 11, задача 01. Слайд «Меню столовой»

Столовая каждый день вывешивает меню на бумаге. Нужен слайд, который сам показывает меню сегодняшнего дня.
Общий список мест для нового типа — в README этапа.

## Как должно работать

- Тип `menu`. Меню задаётся **по дням недели** (Пн–Сб): одно и то же меню повторяется каждую неделю, пока его не
  поменяют. Можно включить «Две недели» (чётная/нечётная) — тогда 12 дней; какая неделя сейчас — по номеру недели
  от 1 сентября текущего учебного года (неделя с 1 сентября — первая).
- В дне — приёмы пищи (до 4): название («Завтрак», «Обед», «Полдник»), время («9:10–9:25», необязательно), строки
  блюд «Каша рисовая — 200 г — 35 ₽» (выход и цена необязательны).
- **Экран**: заголовок «МЕНЮ НА СЕГОДНЯ · ВТОРНИК», приёмы пищи — стеклянными карточками в ряд (1–2 приёма) или
  сеткой 2×2; блюдо — название слева, выход и цена справа серым/акцентом. Длинное меню — шрифт уменьшается (`v-fit`,
  замер по высоте как в WinnersSlide), меньше 28 px — делится на два экрана по очереди.
- После последнего урока (`bellStatus` → `after`) — меню на **завтра** с заголовком «МЕНЮ НА ЗАВТРА · СРЕДА»
  (воскресенье/день без меню пропускаются, как в табло). Нет меню на нужный день — слайд пропускается.
- **Редактор** (окно MenuEditor, живое превью справа): вкладки дней (Пн…Сб, при двух неделях — «1 нед.» / «2 нед.»),
  в дне — приёмы пищи (добавить/удалить/переименовать), текстовое поле блюд построчно. Кнопки «Вставить из Excel»
  (столбцы: блюдо | выход | цена, разбор через `splitTable` из src/scheduleImport.js) и «Скопировать день на…»
  (выбор дней).

## Данные

```js
{ id, type: 'menu', on, title ≤40 /* 'Меню на сегодня' */, theme, duration /* с на экран */, twoWeeks,
  days: { '1': [{ name ≤30, time ≤20, lines ≤2000 /* строки «блюдо — выход — цена» */ }] … '6', а при twoWeeks ещё '8'…'13' } }
```
Разбор строк — чистая функция `parseDishes(text)` в новом `src/menu.js` (+ `menuDay(it, now)` — какой день и меню
показать) с тестами в `tests/`. Сервер `cleanItem`: ключи дней только из списка, ≤4 приёмов на день.

## Проверка (копия сервера)

Меню на Пн–Пт, тест в среду 10:00 (`page.clock`) — среда; в 16:00 — четверг «на завтра»; в пятницу 16:00 — понедельник;
день без меню — слайд пропущен (журнал `.slide.active`); две недели — неделя считается верно на стыке; 25 блюд —
шрифт уменьшился или два экрана; вставка из Excel 3 столбцов; 1280×720 и панель справа.

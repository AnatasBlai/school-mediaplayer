# Этап 11, задача 05. Погода (если у сервера есть интернет)

Показать погоду в Учалах: температура в боковой панели и отдельный слайд с прогнозом. Табло работает и без интернета —
погода просто не показывается.

## Сначала проверь (и спроси владельца при неудаче)

С ПК разработки: `curl "https://api.open-meteo.com/v1/forecast?latitude=54.32&longitude=59.38&current=temperature_2m"`.
Нет ответа — скажи владельцу, что на школьном ПК может понадобиться прокси или разрешение в фильтре; продолжай
делать задачу (без интернета всё должно работать и тихо скрывать погоду).

## Как должно работать

- **Сервер** (`server/weather.js`, запуск из server.js, как расписание копий; под Vite не обязательно): раз в 30 мин
  запрос к Open-Meteo (без ключа, встроенный `fetch`, тайм-аут 10 с):
  `current=temperature_2m,weather_code,wind_speed_10m` и `daily=weather_code,temperature_2m_max,temperature_2m_min`,
  `timezone=Asia/Yekaterinburg`, 4 дня. Результат — в `data/weather.json` `{ at, ok, error?, current, daily }`, SSE
  `weather`. Ошибка — оставить прошлые данные, записать `error` и время попытки. Данные старше 6 ч считать
  устаревшими (не показывать).
- `GET /api/weather` — открыт.
- **Боковые панели** (InfoPanel, CalendarPanel): строка «−3° · облачно» со значком, под часами. Нет свежих данных —
  строки нет (вёрстка не прыгает: место не резервировать). Не ломать `v-fit` дня недели.
- **Слайд** `weather`: «ПОГОДА В УЧАЛАХ», сейчас — крупно температура, значок, описание, ветер «3 м/с»; ниже 3 дня
  прогноза карточками (день недели, значок, макс/мин). Нет свежих данных — слайд пропускается.
- **Значки**: свои простые SVG в коде (солнце, облако, солнце с облаком, дождь, снег, гроза, туман) по коду WMO
  (`weather_code`); таблица «код → значок + слово» — в `src/weather.js` с тестом. Без внешних картинок и шрифтов.
- **Настройки** (окно настроек табло SettingsModal): «Погода: вкл/выкл», место — название и координаты (по умолчанию
  Учалы, 54.32, 59.38). Выключено — сервер не ходит в интернет.
- Окно «Состояние системы» (задача 01 этапа 9): строка «Погода: обновлена 10:30» / «нет связи с интернетом с 8:00».

## Данные

`settings.weather: { on: false, place: 'Учалы', lat: 54.32, lon: 59.38 }` в schedule.json — в `createDefaultData()`
(normalize подмешает к старым файлам). Сервер читает его из schedule.json (как server/playlist.js читает
SCHEDULE_FILE). `data/weather.json` — служебный: не в снимках копий и не в pack.mjs. Слайд: `{ id, type: 'weather',
on, theme, duration }`.

## Проверка

На копии сервера с интернетом — реальные данные; подменить ответ `/api/weather` (`page.route`) на мороз −25, дождь,
грозу — значки и тексты; устаревшие данные — панель без строки, слайд пропущен; выключить погоду — сервер не делает
запросов (лог); 1280×720 — строка в панели не ломает вёрстку.

не нужен» → «нужен только для погоды, без него погода скрывается». README: «Погода».

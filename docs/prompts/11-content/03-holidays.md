# Этап 11, задача 03. Слайд «Сегодня»: праздники и памятные даты

Слайд сам показывает, какой сегодня праздник или памятная дата. Список встроен, школа может добавлять свои даты.
Общий список мест для нового типа — в README этапа.

## Как должно работать

- Тип `today`. Экран: крупно дата «20 ОКТЯБРЯ», ниже названия праздников дня (1–3), у каждого — значок группы
  (Россия / Башкортостан / школа) и короткое пояснение, если оно есть. Тема, анимация, длительность — как у новости.
- Сегодня нет ни одной даты — слайд пропускается.
- В настройках слайда: группы с галочками «Праздники России», «Башкортостан», «Международные дни», «Школьные даты»
  (свои).
- **Свои даты** — в окне слайда: список «дата — текст — пояснение», дата постоянная («ММ-ДД», каждый год) или на
  конкретный год («ГГГГ-ММ-ДД» — для плавающих праздников: Ураза-байрам, Курбан-байрам, День матери, юбилей школы).
  Подсказка в окне: «Ураза-байрам и Курбан-байрам каждый год в разные дни — добавьте их на этот год».

## Данные

Слайд: `{ id, type: 'today', on, groups: ['ru','rb','world','school'], extra: [{ d: 'ММ-ДД'|'ГГГГ-ММ-ДД', title ≤80,
note ≤160 }] ≤100, theme, anim, duration }`. Функция `holidaysFor(it, now)` — чистая, тест в `tests/`
(постоянная дата, дата на год, группа выключена, пустой день).

## Проверка

`page.clock` на 11 октября (rb), 1 сентября (ru), день без дат (слайд пропущен), своя дата на конкретный год
(в другой год не показывается); три даты в один день — влезают на 1280×720 и с панелью справа.

# Этап 11, задача 02. Слайд «С днём рождения!» — именинники дня

В день рождения ученика или учителя экран сам поздравляет. Список заносят один раз в начале года.
Общий список мест для нового типа — в README этапа.

## Личные данные — важно

Даты рождения учеников — персональные данные. Поэтому:
- хранить **только день и месяц** (без года), ФИО и класс;
- на экране по умолчанию — «Имя Ф.» (имя + первая буква фамилии) и класс; переключатель в настройках слайда
  «Показывать полностью: Имя Фамилия»;
- полный список **не отдаётся без входа**: экран получает только сегодняшних (см. API);
- список не попадает в архивы pack.mjs (как auth.json);
- в README — фраза, что список вносится с согласия, решает школа.

## Как должно работать

- **Список именинников** — отдельно от слайда (один на всё табло): окно «Именинники» открывается из окна слайда и из
  раздела «Плейлист» (левая колонка). Таблица: ФИО, класс (или «учитель»), день.месяц; поиск; «Добавить»; удалить.
  «Вставить из Excel»: столбцы ФИО | класс | дата (дата в любом виде «05.03.2012», «5 марта», «05.03» — год
  отбрасывается). Предпросмотр перед добавлением, ошибочные строки — красным с причиной (по образцу ScheduleImport).
  Повторы (то же ФИО и дата) не добавляются.
- **Слайд** `birthdays`: заголовок «С ДНЁМ РОЖДЕНИЯ!», тема, анимация (как у новости), длительность. Экран:
  заголовок, ниже имена карточками (класс — мелко акцентом); учителя — отдельной строкой «Поздравляем учителей:».
  Больше 12 имён — несколько экранов по очереди (по образцу «продолжения» у победителей).
- В понедельник показываются и те, у кого день рождения был в субботу/воскресенье: подпись «в выходные».
  Если суббота учебная (есть уроки) — в понедельник добавить только воскресенье.
- 29 февраля в невисокосный год — 28 февраля.
- Сегодня никого — слайд пропускается.

## Данные и сервер

- `data/birthdays.json`: `{ version: 1, updatedAt, items: [{ id, name ≤80, cls ≤10 /* '8А' | 'учитель' */,
  d: 'ММ-ДД' }] }` — новый `server/birthdays.js`.
- `GET /api/birthdays` — полный список, **только после входа** (впиши в `isAllowed`: этот GET закрыт).
  `GET /api/birthdays/today` — открыт, отдаёт уже отформатированных на сегодня `{ items: [{ name, cls, weekend }] }`
  по часам сервера (формат имени — по настройке слайда, передать параметром `?full=1`).
  `PUT /api/birthdays` — право «Плейлист» (если сделаны права, этап 9 задача 05). SSE `birthdays`.
- Экран перечитывает `today` при старте, по SSE и в полночь.
- Слайд: `{ id, type: 'birthdays', on, title ≤60, full, theme, anim, duration }`.
- Логика выбора дня — чистая функция (`birthdaysFor(items, now, saturdayIsSchoolDay)`) с тестами: выходные,
  29.02, пустой список.

## Проверка (копия сервера)

Вставить 15 человек из Excel с разными форматами дат; `page.clock` на понедельник — видны и выходные; 15 имён — два
экрана; `GET /api/birthdays` без входа — 401, `today` — открыт и без дат; 1280×720 и панель справа.

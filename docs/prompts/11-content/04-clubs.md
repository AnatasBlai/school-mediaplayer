# Этап 11, задача 04. Слайд «Кружки и секции»

Расписание внеурочки висит на бумаге у вахты. Нужен слайд: какие кружки сегодня, где и во сколько.
Общий список мест для нового типа — в README этапа.

## Как должно работать

- Тип `clubs`. Режим (в настройках слайда): «Сегодня» — только занятия сегодняшнего дня, отсортированные по времени;
  «Вся неделя» — все кружки с днями.
- Кружок: название, руководитель, кабинет, для кого («5–7 классы», свободный текст), занятия — до 6 пар «день +
  время» (Пн 15:00–15:45).
- **Экран «Сегодня»**: заголовок «КРУЖКИ И СЕКЦИИ СЕГОДНЯ», строки «15:00 · Робототехника · каб. 210 · Петров А. А.».
  Уже закончившиеся занятия — тусклее, идущее сейчас — с акцентной меткой «ИДЁТ». Все занятия дня закончились или
  их нет — в режиме «Сегодня» слайд пропускается.
- **Экран «Вся неделя»**: карточки кружков сеткой, у каждого дни и время.
- Не влезает — несколько экранов по очереди (по образцу «продолжения» у победителей), шрифт не меньше 28 px.
- **Редактор** (окно ClubsEditor с превью): список кружков, добавить/удалить/переставить, занятия — день (Пн…Сб)
  и время. «Вставить из Excel»: столбцы Название | Руководитель | Кабинет | Для кого | Дни и время («Пн, Ср
  15:00-15:45; Пт 14:00-14:45»), предпросмотр с ошибками красным (по образцу ScheduleImport).

## Данные

```js
{ id, type: 'clubs', on, title ≤60, mode: 'today'|'week', theme, duration /* с на экран */, clubs: [ ≤60
  { name ≤60, teacher ≤60, room ≤20, who ≤40, times: [{ day: 1..6, from: 'ЧЧ:ММ', to: 'ЧЧ:ММ' }] ≤6 } ] }
```
Чистые функции в новом `src/clubs.js`: `parseClubTimes('Пн, Ср 15:00-15:45; Пт 14:00')`, `clubsToday(it, now)`,
`clubScreens(it, now, cols)`; тесты в `tests/`.

## Проверка (копия сервера)

Вставить 10 кружков; `page.clock` на среду 15:10 — идущее с «ИДЁТ», прошедшие тусклые; среда 19:00 — слайд
пропущен в режиме «Сегодня», есть в «Вся неделя»; 30 кружков — несколько экранов; 1280×720 и панель справа.

# Задача 16. Быстрая проверка «всё открывается» одной командой (`npm run smoke`)

Каждая правка требует поднять изолированную копию сервера и пройтись по экрану и редактору. Нужен скрипт, который
делает это сам и падает, если что-то сломалось.

## Как должно работать

`tools/smoke.mjs`, скрипт `"smoke": "node tools/smoke.mjs"` в package.json. Перед запуском нужен свежий `dist/`
(если `dist/index.html` нет — сообщить «сначала npm run build» и выйти с кодом 1).

1. Копия сервера во временной папке (`os.tmpdir()`): `api.js server.js package.json server/ dist/` и общие модули
   из `src/`, которые импортирует сервер (смотри импорты `../src/` в server/*.js, а не список наизусть).
   Копировать **своей рекурсией** (`readdirSync` + `copyFileSync`), не `fs.cpSync` — см. «Подводные камни».
   Данные: по умолчанию пустая `data/` (данные по умолчанию); с флагом `--data` — копия рабочих `data/` **без**
   `auth.json`, `sessions.json` (и `users.json`, если появится) и `media.json`/`media/` (видео не нужно).
2. Запуск `node server.js` на свободном порту (начиная с 8090), ожидание ответа `/api/data`, в конце — остановка
   процесса и удаление папки (даже при ошибке: `try/finally`).
3. Playwright Chromium:
   - экран `/` в 1920×1080 и 1280×720: в течение 5 с появляется `.slide.active`; `POST /api/screens` подменять
     (`page.route`), чтобы тестовый экран не появлялся нигде;
   - редактор `/admin#schedule`, `#playlist`, `#decks`, `#media`: страница открылась, раздел отрисован;
   - собираются ошибки консоли и `pageerror`; 404 на `/background.jpg` — не ошибка.
4. Скриншоты — в папку из аргумента `--out <папка>` (по умолчанию временная, путь напечатать).
5. Итог: таблица «что проверено — ок/ошибка», код выхода 0/1.

## Не трогать

`tools/screenshot.mjs` (остаётся для разовых снимков). Рабочие `data/`, `media/` — только чтение.

## Проверка

`npm run smoke` и `npm run smoke -- --data` проходят; специально добавить `throw` в DisplayApp — скрипт падает
с понятной ошибкой; после прогона нет висящего процесса node на 8090 и временной папки.

Работай по CLAUDE.md, версия — следующая `v0.8.x`. В CLAUDE.md: раздел «Проверка в браузере» — первой строкой
`npm run smoke` (ручная копия сервера остаётся для проверок, которые пишут данные); `tools/` в «Архитектуре».

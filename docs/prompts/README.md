# Задачи для исполнителя (этап 8)

Каждый файл — готовый запрос. Как пользоваться:
1. Новая сессия Claude Code в папке проекта (модель Sonnet).
2. Скопировать текст задачи целиком (или написать `/pravka docs/prompts/04-news-animation.md`).
3. Исполнитель делает, проверяет, коммитит с тегом `v0.8.x` и отчитывается. Проверить результат на экране.

Одна задача — одна сессия: так исполнитель не путает контекст, а каждую правку легко откатить по тегу.

## Шаблон своего запроса

Чем точнее запрос, тем точнее результат. Пишите по пунктам:

```
Задача: <одной фразой, что должно появиться или измениться>
Где: <экран / редактор, какой раздел, какой элемент — как его видит человек>
Как должно быть: <поведение по шагам; что видно на экране; тексты надписей дословно>
Пример: <конкретный случай: «в субботу после 15:00 должно показывать …»>
Не трогать: <что должно остаться как есть>
Проверить: <какие случаи посмотреть на скриншоте>
Работай по CLAUDE.md (порядок работы, проверка на копии сервера), версия — следующая v0.8.x.
```

Если результат не тот — пишите в той же сессии, что именно не так и как должно быть, со скриншотом.

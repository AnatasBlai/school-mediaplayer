# Задача 08. Бегущая строка для срочных объявлений

Нужна бегущая строка внизу экрана поверх любых слайдов: «Сегодня сокращённые уроки», «Собрание родителей в 18:00».
Объявление не надо оформлять слайдом и ждать его очереди.

## Как должно работать

- В редакторе, раздел «Плейлист», новая полоса «Бегущая строка» (по образцу полосы «Гашение экрана» в
  `PlaylistEditor.vue`): переключатель вкл/выкл, список объявлений — каждое: текст (до 200 знаков) + «показывать до»
  (дата, необязательно) + ✕; кнопка «＋ объявление»; переключатель скорости «медленно / обычно».
- На экране, когда включено и есть хоть одно действующее объявление (дата не прошла или не задана): внизу полоса
  высотой ~60 px холста 1080 (тёмное полупрозрачное стекло, белый текст Montserrat 800, ~30 px), текст плывёт справа
  налево бесконечно. Несколько объявлений идут друг за другом через разделитель « • ».
- Скорость постоянная в пикселях в секунду (медленно ~60, обычно ~100 px/с при высоте экрана 1080), не зависит от
  длины текста. Анимация — одно `transform: translateX`, без пересоздания элемента на каждом круге.
- Полоса поверх всех слайдов, включая табло и шаблон «с панелью справа» (перекрывает низ — это нормально, но проверь,
  что не закрывает ничего важного; при необходимости у табло можно приподнять нижний отступ, если строка включена —
  реши по скриншотам). При гашении экрана полосы нет.

## Данные

`playlist.json` → `ticker: { on: false, speed: 'slow'|'normal', items: [{ text, until: 'ГГГГ-ММ-ДД'|'' }] }`.
- клиент: `src/playlist.js` (значение по умолчанию, `apply`, `probeOf` — по образцу `blank`);
- **сервер**: `server/playlist.js` — `cleanTicker()` по образцу `cleanBlank()`, вызвать в `readPlaylist`,
  в обработчике PUT и в `defaultPlaylist`; пустые тексты выбрасывать, не больше 10 объявлений;
- экран: новый компонент `src/display/Ticker.vue`, подключить в `Player.vue` (размеры через `vh`, т. к. Player не
  масштабируемая сцена: высота `calc(100vh * 60 / 1080)` и т. п.). «Действует ли» — проверка по `now` из Player.

## Проверка (копия сервера)

Скриншоты: табло, фото, новость с панелью справа — со строкой; два объявления; объявление с прошедшей датой не
показывается; выключено — строки нет; гашение — строки нет; 1280×720. Видно движение (два скриншота с разницей 1 с).

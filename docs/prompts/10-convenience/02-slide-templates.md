# Этап 10, задача 02. Шаблоны слайдов

Одни и те же объявления делают каждый раз с нуля: «Поздравляем!», «Родительское собрание», «Дежурный класс недели».
Нужны готовые шаблоны и возможность сохранить свой.

## Как должно работать

- В меню «＋ Добавить слайд» (AddSlideMenu.vue) — раздел «Из шаблона»: список шаблонов с миниатюрой-цветом темы и
  названием. Выбор → новый слайд по шаблону в конце очереди (как обычное добавление) и сразу открывается его
  редактор (как у копии новости в v0.8.5).
- **Встроенные шаблоны** (в коде, не в данных; править их нельзя, только использовать):
  - «Поздравляем!» — новость, метка «ПОЗДРАВЛЯЕМ», тема «Закат», анимация zoom, заголовок-заглушка «Имя Фамилия»;
  - «Родительское собрание» — новость, метка «ВНИМАНИЕ», текст «Дата, время, кабинет …»;
  - «Дежурный класс недели» — новость, метка «ДЕЖУРСТВО», заголовок «Дежурит 8А», правило «Когда» — Пн–Сб;
  - «Олимпиада / конкурс» — новость, метка «КОНКУРС»;
  - «До каникул» — обратный отсчёт, заголовок «До каникул»;
  - «Победители олимпиады» — слайд победителей с одной пустой группой.
  Заглушки — серым текстом-подсказкой там, где это возможно, иначе обычным текстом.
- **Свои шаблоны**: в окнах новости, отсчёта и победителей (NewsEditor, CountdownEditor, WinnersEditor) кнопка
  «Сохранить как шаблон» → имя (по умолчанию — заголовок) → шаблон появляется в меню. В меню у своих шаблонов —
  «Переименовать» и «Удалить» (подтверждение). Фото в шаблоне сохраняется ссылкой на медиатеку; файл удалили — шаблон
  остаётся без фото (по образцу `removeMediaFromPlaylist`).
- В шаблон не попадают: `id`, `on`, «Когда» сохраняется (это часть шаблона), срочный режим — нет.

## Данные

`playlist.json` → `templates: [{ id, name ≤40, slide }]`, до 50. `slide` — слайд без id, проверенный тем же
`cleanItem` (сервер). Клиент: `playlist.templates`, `probeOf`, `apply`; функция `slideFromTemplate(t)` рядом с
`cloneSlide`. Сервер: `cleanTemplates`, в `removeMediaFromPlaylist` — убрать `media` и из шаблонов.

## Проверка (копия сервера)

Каждый встроенный шаблон создаёт слайд, редактор открывается, экран показывает его; свой шаблон с фото — сохранить,
создать по нему слайд, удалить фото из медиатеки — шаблон без фото, слайд без фото; перезапуск копии — шаблоны на
месте; длинное имя шаблона в меню на 1280 px не ломает вёрстку.

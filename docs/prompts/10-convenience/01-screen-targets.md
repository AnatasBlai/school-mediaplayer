# Этап 10, задача 01. Слайд только на некоторых экранах

Плейлист один на все экраны. Нужно, чтобы отдельные слайды шли только на выбранных экранах: меню — у столовой,
объявления для родителей — у входа. Остальное по-прежнему общее.

## Как должно работать

- Имя экрана уже есть: `?name=` в адресе (kiosk-settings.txt → `url = …/?name=TV`, `screenName` в Player.vue).
- В окне настроек слайда (SlideSettings.vue) новый блок «Где показывать»: переключатель «На всех экранах» /
  «Только на выбранных» и чипы (`a-chips`) с именами экранов. Список имён = экраны из «Сейчас на экране» (в том числе
  без связи) + имена, уже указанные в других слайдах. Можно вписать имя вручную (экран ещё не подключали).
- В строке слайда в очереди (PlaylistEditor) — метка «только: Холл, Столовая» рядом со сводкой «Когда».
- Экран с именем, которого нет в списке слайда, этот слайд пропускает (`playable()` в Player.vue). Экран **без
  имени** показывает только слайды «на всех экранах».
- Если на экране не осталось ни одного подходящего слайда — как сейчас, FALLBACK (расписание).
- **Срочный режим** показывается на всех экранах, независимо от выбора (как и игнорирует «Когда»).
- Имена сравниваются без учёта регистра и пробелов по краям.
- В «Сейчас на экране» у карточки экрана — «слайдов для этого экрана: N из M».

## Данные

`screens: []` у любого слайда (`[]` или нет поля — на всех), до 10 имён по 40 символов.
- клиент: `makeSlide` (по умолчанию нет поля), `cloneSlide` копирует;
- **сервер** `cleanItem` в server/playlist.js: массив строк, обрезка, без пустых и повторов;
- CLAUDE.md, раздел «Данные» (строка про `when?`).

## Проверка (копия сервера)

Два окна экрана `/?name=Hall` и `/?name=Canteen` (POST /api/screens подменять) + одно без имени: слайд «только Hall»
идёт только в первом (журнал смены `.slide.active` раз в 250 мс); срочный режим на этом слайде — во всех трёх;
все слайды «только Hall» — у Canteen FALLBACK.

как назвать экран в kiosk-settings.txt и выбрать экраны у слайда.

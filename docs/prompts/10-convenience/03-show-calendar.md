# Этап 10, задача 03. Календарь показов: что пойдёт на экране на неделе

Правила «Когда» у каждого слайда свои, и трудно понять, что будет на экранах в четверг. Нужен обзор недели.

## Как должно работать

- В разделе «Плейлист», в левой колонке под «Настройки экрана», кнопка «Календарь показов» → большое окно.
- Окно: неделя Пн–Вс (по умолчанию текущая), «← Пред. неделя», «Эта неделя», «След. неделя →». Сегодняшний столбец
  подсвечен.
- Строки — слайды в порядке очереди (название — `slideTitle`, значок типа). В ячейке:
  - идёт весь день — заливка акцентом;
  - идёт часть дня — заливка + время «8:00–12:00»; только на переменах — «на переменах»;
  - не идёт — пусто; выключенный слайд — строка серая с пометкой «выключен»;
  - отсчёт: после события — пусто; в день события — «день события».
  - если у слайда есть «Где показывать» (задача 01) — под названием «только: Холл».
- Отдельные строки сверху: «Гашение экрана» (периоды по дням) и, если включён, «Срочный режим: показывается только
  „…“» — плашкой над таблицей.
- Клик по названию слайда → его окно настроек (SlideSettings), после закрытия календарь обновляется.
- Окно только для просмотра, ничего не меняет само.

## Логика

Чистая функция в `src/rules.js`: `dayShows(when, date)` → `{ on: false }` | `{ on: true, all: bool, timeText,
breaks }` — с теми же правилами, что `ruleState` (даты включительно, дни 1..7, время через полночь — показать как
«22:00–6:00»). Не дублировать логику `ruleState`: вынести общие части. Тесты в `tests/`.

## Проверка

Слайды с разными «Когда» (даты, дни, время, через полночь, перемены, выключенный, отсчёт с прошедшей датой) — ячейки
верные; переход недель через месяц и год; 1280 px — таблица прокручивается по горизонтали внутри окна, не вся
страница.

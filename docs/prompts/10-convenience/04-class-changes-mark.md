# Этап 10, задача 04. Отметка «есть изменения» у класса в расписании

Ученик смотрит колонку своего класса и не знает, что во вкладке «Изм.» есть изменения для него. Нужна заметная
отметка прямо в колонке класса.

## Как должно работать (экран и редактор)

- На табло (ScheduleBoard.vue) в заголовке колонки класса, у которого есть строка в изменениях, — небольшая плашка
  «ИЗМ.» цветом акцента темы (рядом с подписью «8А», не перекрывая её). Внизу колонки мелко: «Есть изменения —
  смотрите «Изм.»» (если место есть; на 1280×720 проверь — нет места, только плашка).
- Отметка ставится, **только если изменения относятся к показанному дню**: `changesActive(now)` и дата изменений
  (`settings.changesDate`, пусто — сегодня) совпадает с датой дня, который показывает табло. Табло может показывать
  другой день (выходной → понедельник, после уроков → завтра, задача 07 этапа 8) — тогда сравнивать с датой этого дня.
  Нужна функция «какую дату показывает табло» рядом с `dayKey`, без дублирования его логики.
- Класс из строки изменений (`c`) сравнивать после приведения: `parseClassName` из src/scheduleImport.js (латиница →
  кириллица, пробелы, «8 а» → «8А»). Строка «8А, 8Б» или «8АБ» — отметить оба; «8» или «8 классы» — все классы
  параллели. Не распознано — не отмечать.
- В редакторе изменений (вкладка «Изм.» в режиме правки) кнопка «Упорядочить по классам» — сортирует строки по
  параллели и букве (нераспознанные — в конце, порядок между ними сохраняется).

## Логика

Чистая функция в `src/store.js` или отдельном модуле без Vue: `changedClasses(changes, letters)` → Set «8А», тест
в `tests/` (варианты записи класса из списка выше).

## Не трогать

Вид вкладки «Изм.» и текст изменений; «Подводные камни»: подписи «5А» — обводка SVG-фильтром, плашку сделать
отдельным элементом, не меняя подпись.

## Проверка

Изменения на сегодня для 8А и «9 классы» → у 8А и всех 9-х плашки; изменения на завтра — сегодня плашек нет;
выходной — показан понедельник, изменения на понедельник — плашки есть; 1920 и 1280 px, тёмная тема 8 и светлая 5 —
плашка читается.

Работай по CLAUDE.md, версия — следующая `v0.10.x`. В CLAUDE.md: «Поведение, которое легко сломать» — одна строка про
дату показанного дня. README: про отметку и «Упорядочить по классам».

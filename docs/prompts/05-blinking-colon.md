# Задача 05. Мигающее двоеточие в часах

Везде, где на экране показано текущее время, двоеточие между часами и минутами должно мягко мигать раз в секунду
(как на электронных часах). Цифры при этом не должны сдвигаться.

## Где

Текущее время показывается в двух местах:
- `src/display/InfoPanel.vue` — крупные часы в панели справа (`.clock`);
- `src/components/CalendarPanel.vue` — часы в панели справа на табло расписания (`.clock`).
Обе берут время через `toLocaleTimeString(... 'HH:MM')` одной строкой.

## Как сделать

1. Вместо одной строки выводи три части: часы, `<span class="colon">:</span>`, минуты.
2. Анимация `.colon`: CSS `@keyframes`, период 1 с, `opacity` 1 → 0.25 → 1, `ease-in-out`, `infinite` —
   мягкое угасание, а не резкое «вкл/выкл». Только `opacity`.
3. Ширина не должна прыгать: у часов уже `font-variant-numeric: tabular-nums` (где нет — добавь); двоеточие не
   должно исчезать из потока (не `display: none` и не `visibility`).
4. Повтори одинаково в обоих компонентах (можно вынести в маленький общий компонент `src/components/Clock.vue`
   с пропом `date` — если вынесешь, используй его в обоих местах).

## Не трогать

Размеры, цвет и положение часов.

## Проверка

Два скриншота с разницей в 0,5 с: двоеточие в разной яркости, цифры на тех же местах. Обе панели (табло и слайд
с панелью справа), экран 1280×720.

Работай по CLAUDE.md (порядок работы), версия — следующая `v0.8.x`.

# Задача 14. Загрузка расписания из Excel

В начале четверти расписание приходится вбивать в сотни ячеек по одной. Нужно вставлять его из Excel целиком:
выделил таблицу в Excel → Ctrl+C → вставил в редактор.

## Как должно работать

- В разделе «Расписание» редактора — кнопка «Вставить из Excel» (в шапке редактора `AdminApp.vue`, когда открыт
  раздел расписания, или в настройках ⚙ — выбери то, что заметнее). Открывается окно (стили `a-modal` из ui.css):
  1. Выбор дня недели (Пн…Сб).
  2. Большое поле «Вставьте таблицу из Excel» (textarea; данные из Excel приходят строками с табуляцией).
  3. Ниже — **предпросмотр**: таблица, как она распознана (классы по столбцам, уроки по строкам), с подсветкой
     проблем: неизвестный класс (нет такой буквы в настройках) — красным, с кнопкой «Добавить букву».
  4. Кнопка «Заменить расписание на <день> для N классов» и подсказка, что остальные классы и дни не меняются.
  5. После применения — «Готово. [Отменить]» (отмена возвращает прежнее расписание этого дня; хранить копию в памяти
     окна, этого достаточно).
- Формат вставки (написать подсказку с примером в окне):
  - первая строка — названия классов: `5А  5Б  6А …` (допускать `5 А`, `5а`, лишние пробелы; первая ячейка может
    быть пустой или «№»/«Урок» — тогда первый столбец — номера уроков, его пропустить);
  - следующие строки — уроки по порядку (1-й, 2-й …); в ячейке «Предмет» или «Предмет 14» / «Предмет каб. 14» /
    «Предмет 28/34» — кабинет отделяется, если в конце стоит номер (цифры, цифры/цифры, «спортзал»/«с/з»);
  - пустая ячейка — урока нет; пустой хвост обрезается (как в `setLessonField` в `src/store.js`).
- Предметы приводить как есть (только обрезать пробелы); на экране они и так показываются заглавными.

## Где

- Разбор текста — чистая функция в новом файле `src/scheduleImport.js` (без Vue: `parseScheduleTable(text, letters)` →
  `{ classes: [{ grade, letter, lessons: [{ s, r }] }], problems: [...] }`) — её легко проверить в node на примерах.
- Запись — через `state.schedule[grade][day][letter] = lessons` в `src/store.js` (сохранится само, debounce → PUT).
  Строк не больше `settings.lessonsCount` — лишние показать в предпросмотре как ошибку.
- Окно — `src/admin/ScheduleImport.vue`.

## Проверка

Node: 5–6 примеров текста (с номерами уроков и без, «5 а», кабинеты «28/34», пустые ячейки, лишний класс).
Браузер (копия сервера!): вставить таблицу на вторник для 5-х классов → предпросмотр → применить → табло показывает
новые уроки, остальные дни и параллели не изменились (сравнить schedule.json до/после); «Отменить» вернул как было.

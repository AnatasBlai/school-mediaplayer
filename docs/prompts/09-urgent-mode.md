# Задача 09. Срочный режим: один слайд на всех экранах

Иногда нужно немедленно показать одно сообщение на всех экранах (учебная тревога, срочное объявление) и не крутить
ничего другого, пока не отключат.

## Как должно работать

- В разделе «Плейлист» у каждой строки слайда — кнопка «Срочно» (иконка ⚠, подсказка «Показывать только этот слайд
  на всех экранах»). Нажатие → подтверждение «Показывать на всех экранах только „<название слайда>“, пока не
  отключите?» → включается срочный режим.
- Пока режим включён: вверху раздела «Плейлист» (и в шапке редактора рядом со статусом сохранения) красная плашка
  «Срочный режим: на всех экранах „<название>“ [Отключить]». Строка этого слайда подсвечена.
- Экран показывает только этот слайд по кругу (повторяет его, когда тот закончился), **игнорируя** у него `on`,
  правила «Когда» и гашение экрана. Бегущая строка (если уже сделана задача 08) продолжает идти.
- Слайд удалили из плейлиста — режим сам выключается (экран возвращается к обычному показу).
- В «Сейчас на экране» карточка экрана пишет «Срочный режим».

## Данные

`playlist.json` → `urgent: { on: false, id: '' }` (id слайда из items).
- клиент `src/playlist.js`: значение по умолчанию, `apply`, `probeOf` (как у `blank`);
- **сервер** `server/playlist.js`: `cleanUrgent()` — `on` булево, `id` формата id слайда; если такого слайда в items нет —
  `{ on: false, id: '' }`. Вызвать везде, где сейчас `cleanBlank`;
- экран `src/display/Player.vue`: в `following()` и `playable()` — при активном срочном режиме следующим всегда
  становится этот слайд (без проверки `on`/`when`); `blanked` не действует. Смена режима должна применяться сразу
  (watch → `advance()`), а не после конца текущего слайда. Учти, что у табло (schedule/changes) ключ слота 'board'.
- отчёт экрана (`report()`): добавь признак, чтобы NowOnScreen мог показать «Срочный режим».

## Проверка (копия сервера)

Включить срочный режим на новости → экран в течение 1–2 с переключается на неё и повторяет её; плашка в редакторе;
слайд выключен/с правилом «Когда» не на сегодня — всё равно показывается; гашение включено — всё равно показывается;
«Отключить» → обычный показ; удалить слайд → режим выключился. Табло (schedule) в срочном режиме тоже работает.

# Задача 03. Убрать надпись с количеством строк в блоке изменений

В боковой панели (шаблон «с панелью справа») в блоке «ИЗМЕНЕНИЯ» справа от заголовка написано «3 строки».
Эта надпись не нужна — убери её.

## Где

`src/display/InfoPanel.vue`: элемент `<span class="ch-count">` в шапке блока изменений и его стиль `.ch-count`.
Если после этого импорт `plural` из `bells.js` в этом файле больше не используется — убери и его.
Заголовок «ИЗМЕНЕНИЯ» остаётся на своём месте (выравнивание по левому краю), строки изменений и «и ещё N — на табло
«Изменения»» не трогай.

## Проверка

Скриншот слайда с панелью справа (фото, новость или колода) при наличии изменений: надписи нет, заголовок не съехал.

Работай по CLAUDE.md (порядок работы), версия — следующая `v0.8.x`.

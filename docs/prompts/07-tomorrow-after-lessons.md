# Задача 07. После уроков экран показывает расписание на завтра

Вечером ученикам нужно расписание на завтра, а табло весь день показывает сегодняшнее. Нужно: после последнего звонка
дня экран переключается на следующий учебный день.

## Как должно работать (только экран `/`, редактор не меняется)

- Когда уроки сегодня закончились (статус звонков `kind === 'after'` из `bellStatus` в `src/bells.js`), табло
  показывает ближайший **следующий** день, где есть уроки: понедельник–четверг → завтра, пятница → понедельник
  (суббота пустая — пропускается так же, как сейчас).
- Подпись над колонками (там же, где сейчас подпись про выходной — `shiftNote` в `ScheduleBoard.vue`):
  «Уроки закончились — расписание на вторник». Для выходного/дня без уроков подпись остаётся прежней.
- Подсветка текущего урока в показанном «завтрашнем» дне не включается (уже так для `shiftNote`).
- В полночь всё само возвращается к обычной логике.

## Где

`src/components/ScheduleBoard.vue`: вычисление `dayKey` и `shiftNote`. Там уже есть поиск ближайшего дня с уроками
(используется `maxLessonOfDay`) — переиспользуй его, не дублируй. `bell` в этом компоненте уже считается.
Условие `!props.editable && viewingToday` сохранить: в редакторе показывается выбранный день как есть.

## Проверка (подмена времени `page.clock`)

Вторник 10:00 → вторник, подписи нет; вторник 16:00 (после последнего звонка) → среда, подпись «Уроки закончились —
расписание на среду»; пятница 16:00 → понедельник; суббота → понедельник с прежней подписью про выходной;
редактор в 16:00 → сегодняшний день. Скриншоты экрана 1280×720.

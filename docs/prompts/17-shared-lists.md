# Задача 17. Общие списки тем и типов слайдов для клиента и сервера

Списки допустимых тем, типов слайдов, анимаций и шаблонов сейчас **продублированы**: `src/themes.js` ↔
`server/themes.js`, `TYPES` в server/playlist.js и server/decks.js, `NEWS_ANIMS` в src/playlist.js ↔
server/playlist.js, `GRADES`, `LAYOUTS`. Добавил на клиенте и забыл на сервере — сервер молча выбрасывает поле.
Нужен один источник.

## Как должно работать

- Новый модуль `src/catalog.js` — **без Vue и без импортов**, как `src/deckText.js` (его уже импортирует сервер):
  `THEME_KEYS` (все 14), `BOARD_THEME_KEYS` (5…11, changes), `SLIDE_TYPES`, `LAYOUTS`, `NEWS_ANIM_KEYS`, `GRADES`.
  Только ключи; названия и оформление остаются там, где были (`src/themes.js`, `NEWS_ANIMS` в src/playlist.js).
- Сервер (`server/playlist.js`, `server/decks.js`) импортирует списки из `../src/catalog.js`. `server/themes.js`
  удалить (найди все импорты grep-ом).
- Клиент: `src/defaultData.js` `GRADES` и прочие копии — импорт из catalog.js (реэкспорт под старым именем, чтобы
  не трогать все места использования).
- Тест в `tests/` (задача 15): ключи `ALL_THEMES` из src/themes.js совпадают с `THEME_KEYS`; ключи `NEWS_ANIMS`
  совпадают с `NEWS_ANIM_KEYS`; `SLIDE_TITLES` есть для каждого типа. Так расхождение ловится тестом, а не на экране.
- `tools/pack.mjs`: добавить `src/catalog.js` рядом с `src/deckText.js`; задача 16 (`smoke.mjs`) копирует его сама,
  если берёт список из импортов, — проверь.

## Не трогать

Поведение и данные: те же ключи, те же значения по умолчанию. Если найдёшь расхождение между клиентом и сервером —
не исправляй молча, сначала скажи владельцу.

## Проверка

`npm test`, `npm run build`, `npm run smoke`; на копии сервера сохранить новость с темой «Закат» и анимацией — поле
не пропало после перезагрузки редактора. Распаковать `release/…-update.zip` во временную папку и запустить
`node server.js` — сервер стартует (модуль попал в архив).

Работай по CLAUDE.md, версия — следующая `v0.8.x`. В CLAUDE.md: «Архитектура» (catalog.js вместо server/themes.js),
«Подводные камни» — пункт про продублированные списки заменить на «списки — в src/catalog.js», в «Изолированной
копии сервера» — копировать `src/catalog.js`.

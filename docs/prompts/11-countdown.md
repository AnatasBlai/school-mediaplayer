# Задача 11. Слайд «Обратный отсчёт»

Новый вид слайда: «До каникул осталось 12 дней», «До Последнего звонка — 230 дней». Задаётся дата и подпись,
после даты слайд сам перестаёт показываться.

## Как должно работать

- Плейлист: кнопка «＋ Отсчёт» рядом с «＋ Новость». Открывается окно по образцу `NewsEditor.vue` (форма слева,
  живое превью справа): «До чего» (текст, например «каникул», до 60 знаков), дата события (обязательно), время
  (необязательно, по умолчанию 00:00), подпись под числом (необязательно, например «Осенние каникулы с 27 октября»),
  цвет (ThemeSwatches), «Показывать, сек.».
- Экран (на `SlideStage`, оформление как у новостей — стеклянная панель, Montserrat 900):
  сверху «ДО КАНИКУЛ», по центру огромное число и слово с правильным окончанием («12 дней», «1 день», «3 дня» —
  функция `plural` из `src/bells.js`), снизу подпись. Если до события меньше суток — «Уже сегодня!» (или «Осталось
  5 ч 20 мин», если задано время). Поддержать шаблон «с панелью справа» так же, как у NewsSlide (`layout`, `InfoPanel
  in-stage`).
- После наступления даты/времени события слайд **не показывается** (как неподходящий в `playable()` Player), а в
  редакторе у строки метка «событие прошло».
- В строке плейлиста — заголовок «До каникул: 12 дней», миниатюра-плитка как у новости, кнопка «✎ Изменить».

## Данные

Слайд `{ id, type: 'countdown', on, title, date: 'ГГГГ-ММ-ДД', time: 'ЧЧ:ММ'|'', note, theme, duration, layout? }`.
- клиент: `src/playlist.js` — `SLIDE_TITLES`, `makeSlide('countdown')`, `slideTitle`, `hasLayout` (включить countdown);
- **сервер** `server/playlist.js`: добавить `'countdown'` в `TYPES`, ветку в `cleanItem` (дата обязательна —
  без неё слайд выбросить; title/note ограничить по длине; theme из списка тем);
- экран: `src/display/CountdownSlide.vue`, подключить в `Player.vue` (по образцу NewsSlide: `active`, `layout`,
  emit `done` через `duration`); `playable()` — событие ещё не наступило;
- редактор: `src/admin/CountdownEditor.vue` + строка в `PlaylistEditor.vue`; `NowOnScreen` — плитка для типа.
- Если уже сделана задача 01 — темы из `ALL_THEMES`; 04 — анимация не нужна (число и так «живое»).

## Проверка (копия сервера, `page.clock`)

Дата через 12 дней → «12 дней»; через 1, 3, 21, 25 дней — окончания; сегодня с временем через 5 ч → часы и минуты;
дата прошла → слайд пропускается, в редакторе метка; шаблоны full/panel; 1280×720; сохранение после перезагрузки.

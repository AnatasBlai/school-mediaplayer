# Задача 04. Плавная анимация новостей (на выбор)

Слайд новости сейчас статичный. Добавь медленную анимацию, которую можно выбрать у каждой новости. Главное: движение
одно, медленное и плавное на весь показ — без рывков, мелькания и повторов. Слабый ПК: анимировать только `transform`
и `opacity`, одним-двумя элементами, без `filter`.

## Варианты (поле `anim` у слайда news)

| значение | название в редакторе | что происходит за время показа (`duration` слайда) |
|---|---|---|
| `none` | Без анимации | как сейчас |
| `zoom` | Приближение | фото медленно увеличивается `scale(1) → scale(1.08)`, ease-in-out |
| `drift` | Дрейф | фото увеличено на 8 % и плавно смещается по горизонтали на ~4 % своей ширины |
| `parallax` | Параллакс | фото смещается на ~20 px в одну сторону, панель с текстом — на ~10 px в другую |
| `rise` | Появление текста | в первые 1,2 с панель текста поднимается на 30 px и проявляется (opacity 0 → 1), дальше стоит |

Если у новости нет фото, варианты `zoom`/`drift`/`parallax` работают как `rise`. Новые новости — `zoom` по умолчанию,
у старых поля нет → `none`.

## Как сделать

1. `src/display/NewsSlide.vue`: CSS-анимации (`@keyframes`) на `.photo img` и `.card`; длительность —
   `animation-duration` из `item.duration` через CSS-переменную. **Анимация стартует, когда слайд становится активным**
   (проп `active`): слайд заранее лежит невидимым «следующим», и если анимация пойдёт сразу, к показу она уже закончится.
   Например, класс `run` на корне, который ставится при `active` (и снимается при уходе — новая новость начинает с нуля).
   `animation-fill-mode: both`, чтобы после конца кадр не прыгал обратно.
2. В превью редактора (`active=false`) анимация должна быть видна: отдельный проп `preview` → анимация по кругу
   (`infinite alternate`), длительность та же.
3. `src/admin/NewsEditor.vue`: строка «Анимация» с кнопками-переключателем (класс `a-seg`) по таблице выше,
   рядом подсказка одной фразой, что делает выбранный вариант.
4. `src/playlist.js` → `makeSlide('news')`: `anim: 'zoom'`.
5. **Сервер** `server/playlist.js` → `cleanItem` для news: `anim` из списка `['none','zoom','drift','parallax','rise']`,
   иначе `'none'`. Без этого поле не сохранится.
6. Шаблон «с панелью справа» (layout `panel`) должен продолжать работать: панель справа (InfoPanel) не анимируется.
   Фото при анимации не должно вылезать за свой скруглённый блок (`overflow: hidden` у `.photo`).

## Проверка (копия сервера)

Для каждого варианта: серия скриншотов в начале, середине и конце показа (видно, что движение есть и оно небольшое),
новость с фото и без, шаблоны full и panel. В редакторе: выбор сохраняется после перезагрузки, превью анимируется.
Проверь, что следующий слайд-новость, пока ждёт невидимым, анимацию не начинает.

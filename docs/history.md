# История проекта

Справка для людей. Исполнителю читать не обязательно — всё, что нужно для работы, есть в CLAUDE.md.

## Этапы

0. git-репозиторий, .gitignore, проверка сборки и боевого сервера.
1. **v0.1.0** — каркас: `/` (экран) и `/admin` (редактор, отдельный lazy-чанк), SSE `/api/events` вместо опроса раз в 20 с,
   раздача `media/` с поддержкой Range, fallback на index.html. Редактирование расписания переехало в `/admin`.
2. **v0.2.0** — медиатека: потоковая загрузка без лимита в 5 МБ, уменьшение фото в браузере до 1920×1080, список, удаление.
3. **v0.3.0** — плейлист и движок показа: слайды schedule / changes / image / video, длительность, видео до конца,
   предзагрузка следующего, кроссфейд, редактор порядка и вкл/выкл, «＋ В плейлист» в медиатеке.
4. **v0.4.0** — правила показа (даты, время суток, дни недели) + «Сейчас на экране» (отчёты экранов POST /api/screens).
5. **v0.5.0** — шаблоны: «весь экран» или «с панелью справа» (день, дата, часы, звонок, изменения). Кадрирование
   «На весь экран» переименовано в «Заполнить».
6. **v0.6.0** — новости (слайд news) и колоды карточек (факты, вопросы А/Б/В/Г, загадки), стартовый набор колод.
   **v0.6.1** — шаблон «с панелью справа» и у новостей/колод.
7. **v0.7.0** — обслуживание: резервные копии по расписанию, фильтр «Не используются», гашение экрана, киоск,
   автозапуск. **v0.7.1** — pack.bat (пакеты установки/обновления). **v0.7.2** — в день без уроков экран показывает
   ближайший учебный день.
8. **v0.8.0** — CLAUDE.md переписан под исполнителя Sonnet, готовые задачи в `docs/prompts/`.

## Решения владельца

- Все дисплеи показывают один общий плейлист, каналы не нужны. Сервер локальный, авторизации не было до задачи 13.
- Стек: Vue + Node без зависимостей на сервере. Python, отдельная БД не нужны.
- Телевизоры не сенсорные, у учеников только мобильный интернет — до школьного сервера телефоны не достают.
  Поэтому «интерактив» — слайды, которые разворачиваются сами по таймеру (вопрос → ответ). Опросы/квесты с телефонов
  невозможны; квесты отложены.
- Образовательные фото/видео — обычная медиатека (категория «Образование»), отдельный тип не нужен.
- Новости: готовая картинка из Canva (как фото) или слайд news из редактора. Раскладка: фото слева, текст справа.
- Колоды: позиция показа хранится на сервере (все экраны идут дальше вместе). Наполнение — вручную, вставкой списком,
  стартовый набор (факты проверенные и бесспорные).
- Школьный ПК: Яндекс.Браузер, монитор 1920×1080, телевизоры 1280×720, автовхода в Windows нет, ПК работает круглосуточно.
  Резервная копия настраивается в медиатеке (путь, частота, перенос при смене пути). Гасится только страница табло.
- Новые цветовые темы (задача 01) — только для новостей и колод, параллели остаются на своих темах.

## Что на школьном ПК не проверено (на 2026-10-11)

- Координаты телевизора (`x` в kiosk-settings.txt) и поведение `--kiosk` в Яндекс.Браузере.
- Автозапуск через планировщик после перезагрузки.
